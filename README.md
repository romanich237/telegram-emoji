# Telegram Emoji MCP

> MCP-сервер для поиска кастомных эмодзи внутри выбранных Telegram-наборов. Управление доступом — через Telegram-бота.

**Node.js 20+** · **Telegram Bot API** · **MCP** · **SQLite** · **PM2** · **Nginx**

## Установка

Поддерживаются Ubuntu 22.04+ и Debian 12+. Нужны Node.js 20+, npm, git, nginx и iproute2.

```bash
git clone https://github.com/romanich237/telegram-emoji.git
cd telegram-emoji
sudo bash install.sh
```

Установщик сам запросит токен Telegram-бота и ID разрешённых пользователей, создаст защищённый `config.json`, установит зависимости и настроит PM2 и Nginx. Копировать конфигурационные файлы или редактировать их вручную не требуется.

При повторном запуске существующая конфигурация и свободный ранее выбранный порт сохраняются. Если порт занят, установщик подберёт другой случайный порт из диапазона **20000–59999**.

После установки скрипт покажет адрес MCP. Порт необходимо открыть в firewall. Для доступа из интернета настройте HTTPS: не передавайте ключи по открытому HTTP.

## Возможности

- Добавление публичных Telegram Emoji Packs по ссылке.
- Поиск эмодзи внутри выбранного набора.
- Получение `custom_emoji_id` и превью.
- Список наборов и удаление ненужных.
- Авторизация по Telegram ID из списка разрешённых пользователей.
- Временные MCP-ключи, которые выдаёт бот.
- Автообновление из публичной ветки `main`.

## Команды бота

| Команда | Назначение |
|---|---|
| `/start`, `/help` | Справка |
| `/add https://t.me/addemoji/PackName` | Добавить набор |
| `/packs` | Список наборов |
| `/use PackName` | Выбрать набор |
| `/find сердце` | Поиск внутри выбранного набора |
| `/token` | Получить MCP-ключ на 24 часа |
| `/revoke` | Отозвать свои ключи |

## Подключение MCP

Получите ключ командой `/token` в личном чате с ботом. Укажите его в MCP-клиенте как заголовок:

```
Authorization: Bearer <ключ>
```

Endpoint: `http://IP_СЕРВЕРА:ВЫБРАННЫЙ_ПОРТ/mcp`.

Инструменты: `add_emoji_pack`, `list_emoji_packs`, `list_pack_emojis`, `search_pack_emojis`, `annotate_emoji`, `remove_emoji_pack`.

## Обновления и обслуживание

Автообновлятор проверяет `origin/main` раз в минуту. При наличии fast-forward обновления и отсутствии локальных изменений он устанавливает зависимости и перезапускает основной процесс.

```bash
pm2 status
pm2 logs telegram-emoji
pm2 logs telegram-emoji-updater
```

## Ограничения

Telegram Bot API не предоставляет готовые текстовые описания изображений кастомных эмодзи. Поиск по смыслу работает по сохранённым описаниям; визуальный ИИ-поиск можно добавить отдельно.

Конфигурация и база SQLite хранятся локально на сервере. Файл `config.json` не публикуется в GitHub.
