# Telegram Emoji MCP

> MCP-сервер для поиска кастомных эмодзи внутри выбранных Telegram-наборов. Управление доступом — через Telegram-бота.

**Node.js 20+** · **Telegram Bot API** · **MCP** · **SQLite** · **PM2** · **Nginx**

## Установка

Поддерживаются Ubuntu 22.04+ и Debian 12+. Нужны Node.js 20+, npm, git, Nginx. Certbot устанавливается автоматически.

```bash
git clone https://github.com/romanich237/telegram-emoji.git
cd telegram-emoji
sudo bash install.sh
```

Установщик запросит токен бота и разрешённые Telegram ID. Затем открой личный чат с ботом и отправь `/start`. Мастер попросит домен, проверит его A-запись и выпустит сертификат Let's Encrypt. Требуются прямой публичный IPv4, отсутствие AAAA у домена и открытые входящие порты 80 и 443. При ошибке можно повторить настройку кнопкой «Настроить домен». Certbot проверяет срок действия сертификатов по таймеру и перезагружает Nginx после продления.

Для перехода с предыдущей версии один раз запусти `sudo bash install.sh` после обновления кода. Установщик отключит старый публичный HTTP-прокси. Новый адрес появится в боте после настройки домена.

## Возможности

- Добавление публичных Telegram Emoji Packs по ссылке.
- Поиск эмодзи внутри выбранного набора.
- Получение `custom_emoji_id` и превью.
- Список наборов и удаление ненужных.
- Авторизация по Telegram ID из списка разрешённых пользователей.
- Временные MCP-ключи, которые выдаёт бот.
- Автообновление из публичной ветки `main`.

## Команды бота

| Команда | Назначение |
|---|---|
| `/start`, `/help` | Главное меню или мастер первого запуска |
| `/domain` | Настроить домен и HTTPS |
| `/search сердце` | Поиск по всему каталогу |
| `/cancel` | Отменить ввод |
| `/add https://t.me/addemoji/PackName` | Добавить набор |
| `/packs` | Список наборов |
| `/use PackName` | Выбрать набор |
| `/find сердце` | Поиск внутри выбранного набора |
| `/token` | Получить MCP-ключ на 24 часа |
| `/revoke` | Отозвать свои ключи |

## Подключение MCP

Получите ключ командой `/token` в личном чате с ботом. Укажите его в MCP-клиенте как заголовок:

```
Authorization: Bearer <ключ>
```

Адрес HTTPS и ключ можно получить кнопкой «Подключение MCP».

Для подключения из других проектов используйте Streamable HTTP по `https://ВАШ_ДОМЕН/mcp`. Вызовите `search_emojis` с параметрами `{"query":"сердце","limit":5}`. Ответ содержит `custom_emoji_id`, ссылку на набор, формат, защищённый путь превью и готовый HTML для отправки с `parse_mode: HTML`. Превью запрашивается с тем же Bearer-ключом. Повторный `/token` заменяет ранее выданный ключ.

Инструменты: `search_emojis`, `add_emoji_pack`, `list_emoji_packs`, `list_pack_emojis`, `search_pack_emojis`, `annotate_emoji`, `remove_emoji_pack`.

## Обновления и обслуживание

Автообновлятор проверяет `origin/main` раз в минуту. При наличии fast-forward обновления и отсутствии локальных изменений он устанавливает зависимости и перезапускает основной процесс.

```bash
pm2 status
pm2 logs telegram-emoji
pm2 logs telegram-emoji-updater
```

## Ограничения

Telegram Bot API не предоставляет готовые текстовые описания изображений кастомных эмодзи. Поиск по смыслу работает по сохранённым описаниям; визуальный ИИ-поиск можно добавить отдельно.

Конфигурация и база SQLite хранятся локально на сервере. Файл `config.json` не публикуется в GitHub.
