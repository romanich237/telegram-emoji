# Telegram Emoji MCP

> MCP-сервер для поиска кастомных эмодзи в Telegram-наборах. Управление и авторизация через Telegram-бота.

**Node.js 20+** · **Telegram Bot API** · **MCP** · **SQLite** · **PM2** · **Nginx**

## Быстрая установка

Для Ubuntu 22.04+ / Debian 12+ нужны Node.js 20+, npm, git, nginx и iproute2. Установка запускается одной командой после клонирования:

```bash
git clone https://github.com/romanich237/telegram-emoji.git
cd telegram-emoji
sudo bash install.sh
```

Скрипт запросит **токен бота** и **Telegram ID разрешённых пользователей**, сам создаст `config.json`, установит зависимости, настроит PM2 и Nginx.

**Ничего копировать или редактировать вручную не нужно.** При повторной установке настройки и выбранный порт сохраняются.

Nginx автоматически выбирает свободный случайный порт в диапазоне **20000–59999**. Если порт занят, выбирается другой. Локальный Node.js API работает на `127.0.0.1:3210`.

После установки скрипт выведет адрес `http://IP_СЕРВЕРА:ПОРТ/mcp`. Для доступа извне откройте выбранный порт в firewall и **настройте HTTPS**: токены нельзя передавать по открытому HTTP.

## Возможности

- Добавление публичных наборов `https://t.me/addemoji/PackName`.
- Поиск внутри выбранного набора по символу и сохранённым описаниям.
- Получение `custom_emoji_id` и превью.
- Доступ только для разрешённых Telegram ID.
- Временные MCP-ключи через бота, срок действия 24 часа.
- Автоматическое обновление из ветки `main` раз в минуту.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start`, `/help` | Справка |
| `/add https://t.me/addemoji/PackName` | Добавить набор |
| `/packs` | Посмотреть наборы |
| `/use PackName` | Выбрать набор |
| `/find запрос` | Найти эмодзи |
| `/token` | Получить ключ MCP на 24 часа |
| `/revoke` | Отозвать ключ |

## MCP

Получите ключ через `/token` и передайте заголовок `Authorization: Bearer <ключ>` в MCP-клиенте.

Доступны инструменты: `add_emoji_pack`, `list_emoji_packs`, `list_pack_emojis`, `search_pack_emojis`, `annotate_emoji`, `remove_emoji_pack`.

## Обслуживание

```bash
pm2 status
pm2 logs telegram-emoji
pm2 logs telegram-emoji-updater
```

Процесс `telegram-emoji-updater` проверяет `origin/main` раз в минуту и применяет fast-forward обновления, если нет локальных изменений.

**Ограничение:** Telegram Bot API не предоставляет текстовые описания изображений эмодзи. Поиск по смыслу работает только по сохранённым описаниям; визуальный ИИ-поиск пока не добавлен.
